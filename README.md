# 裂境競技場

原創瀏覽器 1v1 即時對戰原型，包含建立／加入房間、房間碼分享、伺服器權威移動、近距離基本攻擊與回合計分。遊戲採用原創名稱與 Canvas 繪製的簡易場景，不使用第三方遊戲素材。

## 本機啟動

需要 Node.js 18 或更新版本。

```powershell
npm install
npm start
```

在瀏覽器開啟 `http://localhost:3000`。一位玩家建立房間後，將 5 位房間碼提供給另一位玩家加入。兩位玩家可在同一個網路環境的不同裝置上，使用主機的區域網路 IP 位址連線。

## 操作方式

- `W`、`A`、`S`、`D` 或方向鍵：移動
- `空白鍵` 或點擊戰場：基本攻擊（需在攻擊範圍內）

目前是遊戲性原型，沒有帳號、配對佇列、技能、持久化資料或公開部署設定。正式公開前，請加上 HTTPS/WSS、連線速率限制及適合部署環境的安全設定。
