# 東風牌桌

純前端瀏覽器版三人日式立直麻將。你與兩位電腦 AI 進行東風戰，沒有真人配對、後端伺服器或連線需求。

## 本機遊玩

直接用瀏覽器開啟 `public/index.html` 即可遊玩，不需要安裝 Node.js 或其他套件。

## 部署到 GitHub Pages

此儲存庫已設定 GitHub Actions：推送到 `main` 後會自動啟用 GitHub Pages，並將 `public/` 發布。部署完成後，可從儲存庫 **Settings → Pages** 取得網站網址；如果自動啟用失敗，請在 **Build and deployment → Source** 將來源設為 **GitHub Actions**。

## 規則與操作

- 三人麻將牌山：萬子只使用一萬、九萬；筒、索、字牌照常使用。
- 東風戰共四局；每局可莊家連莊，玩家點擊手牌打牌。
- 門前聽牌可立直；支援自摸、榮和、碰牌及拔北。
- 拔北會將北牌移出手牌並補摸一張，計作一番寶牌。
- 胡牌需至少一番役；寶牌只加番，不能單獨構成役。
- 隨時可按「重新開局」重洗牌山並開始新戰局。
